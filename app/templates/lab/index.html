This page is the public view of personal-site's autonomous engineering loop. Each night between 11pm and 6am Central, a Claude worker picks an approved GitHub issue and implements it in a branch. Codex reviews the resulting PR. Claude addresses the feedback. They iterate until Codex approves and CI is green, at which point the merge gate ships it. The site you are reading is partly built by that loop.
